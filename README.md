# 공부하면서 만드는 포트폴리오

# 여기까지 만드는데 2달정도 소요
<br>

Lobby -> DedicateServer -> Lobby 사이클 형태로 익스트랙션 전투 파밍게임을 만드는 것이 목적
<br>
<br>
## 큰 그림
<br>

### V 클라가 Standalone에서 연결할 단독 C# Server 구현 및 DB구현
<br>

### V 클라,C#서버 패킷생성 및 사용로직 자동화 (protoBuf 및 UStruct 코드자동생성)
<br>

### V Azure로 C#서버 띄운 후 클라 매칭요청 시 데디인스턴스 실행 후 클라에게 데디케이트서버 접속유도 그 이후 인게임
<br>

3인칭 밀리 전투로 AI 혹은 Player간 전투 후 전리품을 챙겨서 탈출하는 식으로 인게임 컨텐츠 구현

모든 클라의 데디케이트서버 퇴장 시 데디케이트서버 인스턴스 종료처리
<br>
<br>


# [현재 구현 항목]
<br>

###### 데이터 매니저 - JSON 데이터를 Unreal Struct형태의 테이블이나 UDataTable을 들고있어서 전역적으로 접근해서 데이터 ID에 따른 구조체 추출하는기능

###### GAS - 서버 환경아래 작동할 수 있도록 초기화, AttributeSet 데이터매니저를 통해 캐릭터 ID별로 초기화 하도록 수정 

###### 인풋 - 데이터 매니저를 통해 캐릭터 ID 별 IA,GA,로직 데이터바인딩, C++에 함수구현 후 Enum으로 노출되어있다는 가정하에 블루프린트로만으로도 인풋로직바인딩이 가능

###### 콤보 - ComboManagingComponent를 만들어서 캐릭터의 상태에 따라서 ComboContext를 선택하고, 현재 상황에 가장 알맞는 콤보를 중개하여 실행시키는 시스템을 제작

###### 아이템 - 인벤토리, 컨테이너형 인벤토리(벨트, 주머니..) 같은 아이템시스템 FastArray형태로 관리하여 제작, 데이터의 경우 아이템의 동적데이터만 리플리케이션해서 네트워크 코스트 최적화

###### 레벨 - 타이틀화면 꾸미기 및 데디케이트 서버 접속기능(아직은 IP로), 랜드스케이프 브러쉬나 폴리지 절차생성으로 간단한 게임맵 생성, 자기장 시스템(페이즈 시스템 기반)

###### 서버,DB - 서버 제작 후, DB연동, Azure 가상머신에 배치 (Redis, MongoDB..  연동만 된 상황 Job확장으로 패킷에 따른 컨텐츠 확장해야함)

###### 프로토버퍼 패킷 자동화 - Proto를 읽어 서버, 언리얼클라이언트에 공유되는 패킷 직렬화 코드 자동생성하는 기능 추가 (언리얼은 USTRUCT 자동화, Protobuf <-> UStruct 자동변환, 블루프린트 노출, 패킷핸들러 자동생성)

###### 매칭서버,메인서버,클라이언트 분리 - 메인서버(DB 및 중앙서버) 와 매칭서버(데디케이트서버 인스턴스 생성 및 삭제)는 gRPC로 통신, 클라이언트와 메인서버는 소켓으로 통신하여 매칭서버와 중개해줌

###### 노티파이 기반 시스템 - Realm에 따라서 노티파이 트리거링 최적화, 몽타쥬가 돌 동안 노티파이끼리 통신가능한, 데이터 커스터마이징 가능한 일시 캐싱시스템 추가

###### 이벤트 매니저 - 불규칙한 이벤트에 대해서 전역적으로 이벤트를 걸고, 원하는 때 호출할 수 있는 이벤트 매니저 추가

###### 공격,피격 파이프라인 - 현재 애니메이션에 맞는 적 탐지 시스템 (메쉬부착형태, 박스형태), 탐지 후 공격처리를 하는 파이프라인 제작

###### 카메라매니저 - 카메라의 변수별로 매니저를 두어 플레이어의 상태에 따라서 동적으로 변화하하는 시스템 제작

###### UI - HP,스태미너,미니맵,자기장,스킬,인벤토리 ...

###### 인터랙션 - 범용 인터랙션 컴포넌트 제작, 멀티인터랙션 기능

###### 루팅 - 인터랙션컴포넌트를 이용하여, 시체 루팅,컨테이너 루팅 컨텐츠 추가

###### 네트워크 동기화 - Client Prediction 실패 시 커스텀롤백 기능, CharacterMovement ServerMove_PerformMovement 커스터마이징, 클라 MovePacket, FCharacterNetworkMoveData 커스터마이징

###### 범용 상태 관리 - GAS가 들고있는 State를 참조하는 ManagedState 객체를 이용하여 연관있는 태그에 대하여 이벤트를 대리호출해주는 시스템

###### 파쿠르 시스템 - 모듈러식 Parkour 객체를 장착 후 범용상태를 참조하여 조건 체크 후, 객체에 정의된 파이프라인을 따르며 파쿠르 로직을 실행함
